Stream Capture

Record a YouTube stream from its first minute, then turn it into a searchable transcript on this Mac. It works while the stream is still live.

How it works
  1. Record. yt-dlp --live-from-start rewinds to the stream's first minute, pulls it down in 5-second chunks, then keeps up with the live edge until the stream ends or you hit Stop. Only the audio is saved.
  2. Snapshot. While recording, the file on disk is still being written. "Transcribe" uses ffmpeg to copy everything captured so far into a clean file, without interrupting the recording.
  3. Transcribe. mlx_whisper runs Whisper large-v3-turbo on your Mac's GPU. Lines show up as they finish. The first run downloads the model (about 1.6 GB).
  4. Keep it. Everything stays in stream-capture/jobs/<video-id>/, including your copy of the ending they plan to cut.
